# ระบบรายงานสถานการณ์อุทกภัย โรงพยาบาลไทรโยค จังหวัดกาญจนบุรี
### (Flood Situation Report Web Application - Google Sheets + GitHub Pages + Google Apps Script)

ระบบเว็บแอปพลิเคชันสำหรับดึงข้อมูลสถานการณ์น้ำจาก Google Sheets (ชีต `data`, คอลัมน์ `A-AL`) มาสร้างเป็นภาพสารสนเทศ (Infographic) บนหน้าเว็บแบบ Interactive รองรับการเลือกวันที่ดูข้อมูล แสดงตัวอย่างแบบ Real-time และสั่งพิมพ์รายงานขนาด A4 ได้ทันที

---

## 🌟 คุณสมบัติเด่น (Features)
1. **เลือกวันที่รายงานได้ (Date Selector)**: ดึงข้อมูลวันที่ทั้งหมดจาก Google Sheets มาใส่ใน Dropdown เลือกดูรายงานย้อนหลังหรือวันล่าสุดได้ทันที
2. **แสดงผล Infographic สวยงาม คมชัด**: วาดภาพผ่าน HTML5 Canvas ความละเอียดสูง (1024x1536 px) ตรงตามฟอนต์ `Prompt` และเลย์เอาต์แม่แบบโรงพยาบาลไทรโยค
3. **ตรวจสอบและแก้ไขข้อมูลแบบ Real-time**: มีฟอร์ม 38 รายการด้านขวาให้ตรวจสอบหรือแก้ไขตัวเลข/ข้อความ เมื่อพิมพ์แก้ไข ภาพจะอัปเดตแบบสดทันที
4. **สั่งพิมพ์รายงาน (Print)**: มีปุ่ม `🖨️ สั่งพิมพ์รายงาน` ออกแบบ CSS `@media print` สำหรับกระดาษ A4 แนวตั้งโดยเฉพาะ ตัดแถบควบคุมออก เหลือเฉพาะตัวรายงานอย่างเป็นทางการ
5. **ดาวน์โหลดรูปภาพ (Download PNG)**: ส่งออกเป็นไฟล์รูปภาพ PNG คุณภาพสูงสำหรับแชร์ลง LINE, Facebook หรือกลุ่มรายงานด่วน
6. **ระบบหน้า Admin สำหรับปรับแต่งตำแหน่งและเพิ่มข้อความ (Visual Layout Editor)**:
   - ปรับตำแหน่ง (X, Y) ของตัวเลขและข้อความทุกจุดบนรูปภาพแม่แบบ 1024x1536 px ได้อย่างอิสระ
   - ลากวาง (Drag & Drop) หรือกดปุ่มลูกศร / Stepper ละเอียดระดับ 1 พิกเซล
   - เพิ่มข้อความ/ตัวอักษรใหม่ (Custom Text) ลงบนจุดใดก็ได้ของรูปภาพ พร้อมเลือกขนาด ความหนา และสีได้ตามต้องการ
   - บันทึกการตั้งค่าลงเครื่อง (localStorage) โดยอัตโนมัติ และส่งผลต่อหน้าหลักทันที
   - ส่งออก (Export) และ นำเข้า (Import) ไฟล์พิกัด JSON เพื่อสำรองข้อมูลหรือแชร์ระหว่างเครื่อง
   - มีปุ่มคืนค่าพิกัดเริ่มต้น (Reset to Factory Defaults) เสมอ

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์
- `index.html`: ไฟล์หน้าเว็บหลักสำหรับดูรายงาน เลือกวันที่ และสั่งพิมพ์
- `admin.html`: หน้าจัดการตำแหน่งและเพิ่มข้อความ (Admin Visual Layout Editor)
- `admin.js`: ระบบ Canvas Interactive Editor สำหรับลากวาง ปรับแต่งพิกัด และเพิ่มตัวอักษร
- `layout_default.js`: ไฟล์กำหนดพิกัดมาตรฐานของทุกจุดบนแม่แบบ พร้อมระบบบันทึกและโหลด
- `style.css`: สไตล์หน้าจอ ทั้งหน้าหลัก หน้า Admin และระบบจัดหน้าพิมพ์กระดาษ A4
- `app.js`: ระบบดึงข้อมูล Google Sheets (JSONP bypass CORS), จัดการ Dropdown วันที่ และวาด Canvas ตามพิกัดที่ปรับแต่ง
- `assets.js`: แคช Base64 สำหรับไอคอนและป้ายสถานะ (Pills/Badges) เพื่อความเสถียร
- `000.png`: รูปภาพแม่แบบเปล่าของโรงพยาบาลไทรโยค (1024x1536 px)
- `Code.gs`: สคริปต์ Backend สำหรับ Google Apps Script
- `gas_index.html`: ไฟล์รวมสำเร็จรูป (Single File Bundle) สำหรับคัดลอกลงใน Google Apps Script Web App
- `generate_report.py`: สคริปต์ Python สำหรับเจนรูปภาพอัตโนมัติผ่าน Command Line

## 🚀 วิธีการติดตั้งและใช้งาน

### 1. วิธีเปิดทดสอบบนเครื่องตนเอง (Localhost)
เปิด PowerShell ในโฟลเดอร์ `c:\webapp\water` แล้วรัน:
```powershell
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`

---

### 2. วิธีขึ้นระบบบน GitHub Pages (ฟรี 100%)
1. สร้าง Repository ใหม่บน GitHub (เช่น ชื่อ `hospital-water-report`)
2. อัปโหลดไฟล์ต่อไปนี้ขึ้น GitHub:
   - `index.html`
   - `style.css`
   - `app.js`
   - `assets.js`
   - `000.png`
   - `sheet_data.json`
3. ไปที่แท็บ **Settings** ของ Repository -> เลือกเมนู **Pages** (ทางซ้าย)
4. ในส่วน **Branch** ให้เลือก `main` (หรือ `master`) โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์เว็บไซต์ เช่น `https://<ชื่อผู้ใช้>.github.io/hospital-water-report/` สามารถเปิดใช้งานได้ทันที

---

### 3. วิธีติดตั้งเป็น Google Apps Script (GAS Web App)
1. เปิด Google Sheets: `https://docs.google.com/spreadsheets/d/1-oqfYnCyY2djg9WbASAfH21nX8r39R6j-z0UUs-vd4g/edit`
2. ไปที่เมนูด้านบนเลือก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ในไฟล์ `Code.gs` ให้ลบโค้ดเดิมแล้วคัดลอกโค้ดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวาง
4. กดเครื่องหมาย **+** ข้างไฟล์ -> เลือก **HTML** แล้วตั้งชื่อว่า `Index`
5. เปิดไฟล์ `gas_index.html` แล้วคัดลอกเนื้อหาทั้งหมดมาวางทับในไฟล์ `Index.html`
6. กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** มุมบนขวา -> เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
7. เลือกประเภทเป็น **เว็บแอปพลิเคชัน (Web app)**
   - คำอธิบาย: `ระบบรายงานสถานการณ์น้ำ รพ.ไทรโยค`
   - ดำเนินการในฐานะ: `ฉัน (Me)`
   - ผู้มีสิทธิ์เข้าถึง: `ทุกคน (Anyone)`
8. กด **ทำให้ใช้งานได้ (Deploy)** แล้วอนุมัติสิทธิ์ (Review permissions)
9. จะได้รับ URL เว็บแอปพลิเคชัน สามารถส่งต่อให้เจ้าหน้าที่เข้าใช้งานผ่านเบราว์เซอร์ได้ทันที
